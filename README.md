# Random String Generator

A simple React application that generates random alphanumeric strings. This project demonstrates the use of React Hooks including **useState**, **useCallback**, and **useEffect**.

## 🚀 Features

- Generate random alphanumeric strings
- Customize string length
- Automatically generates a string on page load
- Regenerate strings with a button click
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- React
- Vite
- JavaScript (ES6+)
- CSS
